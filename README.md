# Achados do Darcy

Demonstração de achados e perdidos do CETI Professor Darcy Araújo.

## Abrir no computador

Extraia o ZIP e abra `public/index.html` no navegador.

## Publicar na Vercel

1. Coloque os arquivos extraídos em um repositório Git.
2. Importe o repositório na Vercel e use como raiz a pasta que contém `vercel.json`.
3. Publique usando a configuração do projeto. Não é necessário cadastrar variáveis de ambiente.
4. Confira o link em uma janela anônima antes de gerar o QR code.

A demonstração usa dados fictícios. Os cadastros ficam na página aberta e são descartados ao recarregar ou clicar em **Reiniciar demonstração**.
